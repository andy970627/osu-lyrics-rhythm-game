# osu! 歌詞節奏遊戲

跟著歌詞與旋律點擊音符的 osu 風格節奏遊戲，以及相關的 YouTube Music 擴充套件。

| 路徑 | 內容 |
| --- | --- |
| `osu-lyrics-game.html` | 單一檔案網頁遊戲：歌詞打擊、osu 計分/HP/評級、自選音樂 + LRC、匯入 `.osz` 譜面。直接用瀏覽器開啟即可。 |
| `youtube-music-rhythm-extension/` | Chrome 擴充：在 YouTube Music 播放頁疊加節奏點擊小遊戲。 |
| `better-lyrics-rhythm/` | [Better Lyrics](https://github.com/better-lyrics/better-lyrics) 的非官方 fork（GPL-3.0），加入「歌詞節奏模式」。詳見 `better-lyrics-rhythm/FORK.md`。 |

原本放在 `anki-quizlet-importer-extended` 的 `claude/osu-lyrics-game-1tpmpg` 分支，已連同 commit 歷史拆出成獨立 repo。
